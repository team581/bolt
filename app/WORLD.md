# Bolt World

Operational context for Team 581's software team.

## Who we are
- FRC Team 581 (high school robotics).
- The software subteam writes the robot code in Java on top of WPILib, with vendor libraries from CTRE (Phoenix), REV, and others as needed.
- We use Gradle (`./gradlew`) for builds and Spotless for formatting (`./gradlew spotlessApply`).

## Where code lives
- GitHub org: `team581`.
- Most code reviews and project tracking happen on GitHub (issues, PRs, and Projects).

## How we work
- Default branch is usually `main`.
- We follow Trunk-based development where reasonable; long-running feature branches are the exception.
- Commit messages are short and present-tense.
- When in doubt about formatting, run Spotless rather than hand-editing whitespace or import order.

## What you can do today
- Answer coding questions about WPILib, Java patterns, and Team 581's repos.
- Open and update GitHub issues and pull requests via the GitHub plugin.
- GitHub Projects (board state changes) are not yet wired up; tell users to update the board manually for now.
