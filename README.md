# Bolt

Team 581's instance of [Junior](https://junior.sentry.dev) — a Slack bot that answers coding questions and manages GitHub issues/PRs.

See [SETUP.md](./SETUP.md) for the operator runbook.

## Development

```sh
pnpm install
cp .env.example .env.local
pnpm dev
```
